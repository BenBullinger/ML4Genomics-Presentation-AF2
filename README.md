# AlphaFold 2 presentation

This repository contains a presentation of the paper: ["Highly accurate protein structure prediction with AlphaFold" (Jumper et al., 2021)](https://doi.org/10.1038/s41586-021-03819-2) (code available at: [google-deepmind/alphafold](https://github.com/google-deepmind/alphafold)) as part of the course "Machine Learning for Genomics (263-5351-00L)" at ETH Zurich.
